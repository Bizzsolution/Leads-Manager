# LeadDesk

Single-file PWA to manage leads, follow-ups, quotations, meetings and shareable brochures/demo videos. Built for Indian SMEs. No backend: all data stays in the user's browser (localStorage), with JSON backup/restore.

## Features
- Today view: overdue and due follow-ups, week's meetings, pipeline value
- Lead stages, activity timeline, WhatsApp/call/email shortcuts
- Quotation builder with GST, printable to PDF, WhatsApp summary
- Library of brochure/video/website links, one-tap share to a lead
- Meetings with Google Calendar link
- Offline support, installable on phone

## Run locally
Open `index.html` in a browser, or serve the folder: `python3 -m http.server 8000`.
